# Undangan Pernikahan Digital Wais & Lulu (SPESIAL 04)

Website undangan pernikahan digital satu halaman (*single-page*) dengan pendekatan desain **mobile-first**, sentuhan klasik tradisional **Jawa**, dan estetika **botanical pampas**.

## ✨ Fitur Utama

- **Layar Pembuka (Opening Envelope Modal)**: Menyapa nama tamu secara personal via parameter URL (`?to=Nama+Tamu`).
- **Cover / Hero Section**: Foto pasangan berbingkai *arch*, tipografi mewah, dan tombol *Save The Date* terintegrasi Google Calendar.
- **Profil Mempelai (Bride & Groom)**: Divider pita bertuliskan Bride & Groom berikon gunungan, foto mempelai, nama orang tua, dan ikon sosial media.
- **Kutipan Suci**: QS. An-Nur: 32 dengan kaligrafi dan layout terpusat.
- **Love Story**: Foto pasangan dan timeline vertikal perjalanan cinta (*Awal Cerita* & *Lamaran*).
- **Countdown Timer**: Hitung mundur interaktif real-time menuju hari bahagia (14 Maret 2027).
- **Jadwal Acara & Google Maps**: Kartu Akad Nikah & Resepsi dengan peta lokasi interaktif.
- **Galeri Foto**: Grid foto ganda dengan fitur *Lightbox modal preview*.
- **Amplop Digital**: Desain kartu ATM Bank BNI realistis dengan tombol *Copy No. Rekening* dan notifikasi toast.
- **Ucapan Terima Kasih & Penutup**: Ungkapan rasa syukur dan doa restu yang tulus kepada para tamu undangan dan keluarga besar.
- **Floating Navigation Bar**: Menu navigasi melayang di bagian bawah layar.
- **Pemutar Musik**: Piringan audio melayang untuk memutar lagu latar romantis.

## 🚀 Cara Menjalankan

Buka berkas `index.html` langsung di browser, atau jalankan server lokal:

```bash
node server.cjs
```

Buka di browser:
```
http://localhost:3000/?to=Nama+Tamu
```

## 🛠️ Teknologi

- HTML5
- CSS3 & Tailwind CSS
- Vanilla JavaScript
- Lucide Icons & Google Fonts
